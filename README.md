# Bad Dog, No Chrome

A tiny Chrome extension that closes new windows when 3+ are already open in the current profile.

## Installation
1. Clone the repo locally:
```sh
git clone git@github.com:benholmen/bad-dog-no-chrome.git [/sensible/local/path/bad-dog-no-chrome]
```
2. Open Google Chrome extensions page <a href="chrome://extensions/">chrome://extensions/</a>
3. Enable Developer Mode
4. Click Load Unpacked
5. Choose the folder you selected
